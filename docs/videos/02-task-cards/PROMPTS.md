# 原始需求与图像生成 prompt

## 视频要求

> 你做个新的视频吧，背景铺满这个图标。声音的人声音量降低50%，配乐不变。
> 还是idle，任务收起的状态，然后，一个任务，二个任务，三个任务，然后折叠状态，然后展开状态。然后收起状态。然后完成一个任务。

用户同时提供鲸鱼图。鲸鱼图作为底纹，不替换人物或围裙图案。

## 示意图与最终修订

> 展开前，加入这个。配个文本：精美的交互设计（胡说）

用户提供三态布局示意图，随后明确：

> 我看了前一个视频，前边idle的时间太长了，3s就可以了

> 你视频里的状态栏的位置不太对吧

> 交互设计的那个图，持续5秒中，放到 折叠态前出现。淡入淡出各0.5秒

以最后一条修订为准：示意图 24–29 秒，之后才折叠。原图保持，不把灰色和黄色示意块改成虚构界面。

## 实际鲸鱼提取 prompt

完整英文原文保存在 [whale-extraction-prompt.txt](whale-extraction-prompt.txt)。它要求从用户提供图片中提取蓝鲸及三滴水，保留右侧尾巴、圆身体、浅腹纹与原比例，移除布料和背景，输出透明底，不新增眼睛、笑脸、文字或圆形徽章。

其余画面是 Unity 渲染与 AppKit / ScreenCaptureKit 合成，不使用文生视频。人声沿用第一版已接受的缓存，仅调整音量及前 3–7 秒的整周相位补齐，不重新请求语音模型。
