# 任务卡片视频分镜

| 时间 | 内容 |
|---|---|
| 0–3 秒 | 鲸鱼背景，idle，任务卡片收起 |
| 3–11 秒 | 一个任务、一口锅 |
| 11–19 秒 | 两个任务、两口锅 |
| 19–24 秒 | 三个任务、三口锅 |
| 24–29 秒 | 原始收缩／折叠／展开示意图，文字“精美的交互设计（胡说）” |
| 29–31 秒 | 玻璃卡片折叠堆叠 |
| 31–34 秒 | 卡片向上展开 |
| 34–37 秒 | 再次收起卡片 |
| 37–50 秒 | 完成一个任务，锅盖、米饭和粒子；发电机与另外两口锅继续保留 |

示意图总长 5 秒，包含 24–24.5 秒淡入、24.5–28.5 秒完整显示、28.5–29 秒淡出。折叠状态只能在 29 秒之后出现。

画面坐标以 540×540 pt 原生画布为准：状态条中心 X=270 pt、Y=112 pt；只在离线录制中将人物画布 bounds 原点设为 Y=−40 pt，修正视频里的状态条位置，不改变人物可见大小。背景鲸鱼每个 88×59 pt，112×88 pt 错列排布，白底上 20% 不透明度。
