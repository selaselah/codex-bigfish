# 手摇发电机视频分镜

| 时间 | 画面与动作 | 声音 |
|---|---|---|
| 0–7 秒 | 白底 idle，固定人物比例 | 原创轻快伴奏，无嘿哟人声 |
| 7–17 秒 | 一个任务、一口锅，面朝右，两手带动全身摇发电机 | 嘿、哟重音跟随摇柄 |
| 17–27 秒 | 两个任务、两口锅，保留松弛电线和发电机 | 同步节奏继续 |
| 27–37 秒 | 三个任务、三口锅 | 同步节奏继续 |
| 37–约 39.4 秒 | 完成一个任务，欢呼、锅盖弹起、米饭碗和粒子效果；其余两锅仍在 | 停止嘿哟，保留完成音效 |
| 约 39.4–50 秒 | 两个任务继续发电，镜头不缩放 | 达到工作权重后恢复嘿哟，片尾渐弱 |

最终声音排程还要求工作权重至少 0.90，并保留结尾安全留白；精确采样由 `mix_voice.py` 根据实际动作 CSV 决定，不能仅按表格均匀贴音。

本片没有后两版的鲸鱼底纹、交互设计插图或玻璃任务卡片演示。相机通过整段动作预检确定一次固定取景，人物不会随任务数量缩小。
