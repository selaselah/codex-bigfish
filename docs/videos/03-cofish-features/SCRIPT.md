# CoFish 新功能视频分镜

| 时间 | 字幕与展示 |
|---|---|
| 0–3 秒 | CoFish · 全新图标；idle，应用图标与菜单栏图标 |
| 3–6 秒 | 一个任务，一口锅 |
| 6–9 秒 | 一起开工；两个任务 |
| 9–12 秒 | 轻盈发丝，也有惯性；三个任务 |
| 12–17 秒 | 精美的交互设计（胡说）；原示意图，淡入淡出各 0.5 秒 |
| 17–20 秒 | 原生液态玻璃，收放自如；折叠与展开 |
| 20–24 秒 | 点哪口锅，就看哪个任务；选中卡片、再次点击抖动 |
| 24–28 秒 | 悬停操作 · 关闭本轮，不停止任务 |
| 28–31 秒 | 点锅找回卡片 |
| 31–35 秒 | 拖动状态栏，整组跟随 |
| 35–39 秒 | 完成了，米饭和绿卡等你查看 |
| 39–43 秒 | 继续聊天，原卡片变回白色 |
| 43–45.5 秒 | 每个聊天，只保留一张卡片 |
| 45.5–46.5 秒 | 点绿卡已读，其余列表保持展开 |
| 46.5–49 秒 | 菜单栏入口 · 设置与退出 |
| 49–51 秒 | 任务再多，锅碗不缩水 |
| 51–55 秒 | 原尺寸堆叠 · 插线板按需升级 |
| 55–57 秒 | 锅盖一跳，又是一锅完成 |
| 57–60 秒 | CoFish · 陪你把任务，一锅锅完成；片尾品牌画面 |

全片人物相机固定，锅碗保持当时的 1.75 原始道具比例。菜单片段是使用正式图标绘制的入口示意，不是系统菜单栏的实际录像。拖动和点击由隔离宿主脚本驱动，指针为演示叠加；不是多屏拖动边界或完整交互测试。

人声沿用第一版的四组语调，仍为降低 50% 的音量；仅在工作权重足够时按实际摇柄相位放置，idle 与欢呼不唱。伴奏沿用原源与 0.80 增益，49.75 秒起用 0.25 秒交叉渐变延长至 60 秒。
