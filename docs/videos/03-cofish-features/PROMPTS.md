# 原始需求与封面 prompt

## 视频要求

> 制作一个新的视频？包括新的icon（应用和任务栏的），以及上次视频后新增的功能。

继承第二条视频已经确认的鲸鱼背景、3 秒 idle、示意图置于折叠前且总长 5 秒、淡入淡出各 0.5 秒、人声音量降低 50%、伴奏不变。新增功能按 `SCRIPT.md` 展示；片中使用当时批准的 Icon-v6、MenuIcon-v7，不使用后来修订的新功能来改写已发布内容。

画面来自 Unity 实际模型、程序动作和原生 AppKit 合成，没有视频生成模型 prompt。声音沿用第一版已有语音缓存，不另外生成真人声音。

## 封面要求

> 生成一个视频封面

> 4:3 和 16:9，你给我 16:9 同时兼容 4:3（平台会裁掉左右）

> 这个图也放在Github的README里吧

实际两次图像编辑 prompt 原文：

- [初始方形封面](prompts/Prompt.txt)：以当时人物、发电机、三口锅和已批准图标为参考，保持角色身份与造型。
- [16:9 与 4:3 安全区](prompts/Prompt-16x9.txt)：横向 1920×1080，平台居中裁剪为 4:3 时保留 X=240..1680；文字、人物、呆毛、发电机、锅和主要连接线放在更保守的 X=300..1620 内，两侧只放装饰背景。

精确文案只有：`CoFish`、`陪你把任务，一锅锅完成`、`工作中 · 3 项`。不增加水印、额外角色、额外四肢、裁剪辅助线或新的图标设计。参考图片、生成原图和最终 PNG 不复制进本档案；既有 README 封面保留原展示用途。
