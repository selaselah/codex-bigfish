# Codex 与大肥鱼联动

保留官方 **Mini** 的快速聊天、语音与活动控件；Unity 桌宠作为独立透明窗口接收本机任务状态。没有将 Unity 原生窗口嵌入 Mini，不修改客户端安装文件、不启动另一套模型、不使用 API Key。

## 当前桌面方案

```sh
python3 Integrations/codex/install-observer.py
```

安装一个当前用户的 macOS LaunchAgent，登录后自动运行 `observe.py`。它监听本机 `$CODEX_HOME/sessions`（默认 `~/.codex/sessions`）的会话文件。生命周期桥只记录任务标识、状态、到期时间与事件时间。任务列表另行提取任务标题、最近一条公开助手消息（最多600字符），以及“正在思考”“已运行命令”等通用状态。它不保存用户提示、推理正文、工具参数或工具输出，不发送网络请求。

桌面版当前使用自己的后台进程。实测本聊天没有运行新安装的 CLI hooks；共享 App Server 的运行状态也不包含这条聊天。因此采用本机会话事件日志兼容适配。**日志格式不是稳定的公开 API**，需随 Codex 升级验证。不能将它宣称为官方 Mini 插件接口。

| 本机事件 | 大肥鱼 |
| --- | --- |
| task_started、活动回合中的进度事件 | 工作中 |
| 可识别的审批/提问事件（若客户端写入） | 等待确认，属尽力支持 |
| task_complete | 本回合结束；其他聊天也空闲时庆祝 |
| turn_aborted、shutdown_complete | 清理该聊天状态 |

同时跟踪多个本机会话：等待确认优先，其次工作中，最后完成。一个聊天结束不会把其他仍在工作的聊天切回待机；但每个新结束的回合都会触发一次庆祝与 4 秒提示，即使还有其他聊天在工作。状态条显示剩余任务数量；所有聊天结束后 12 秒回到待机。回合结束不代表用户目标一定成功实现。未知事件不会被推测成错误或成功。

监听器每秒检查文件追加，每 5 秒发现新会话；首次恢复最近的生命周期边界和同回合近期进度，不重播历史庆祝。状态一小时无刷新后过期，避免异常退出后永久卡住。启动前已经运行超过一小时且没有近期生命周期边界或进度的任务，可能到新事件出现后才被识别。除今天、昨天目录外，还以只读SQLite连接读取最近两天更新的本机任务元数据（最多256项），补齐起始日期较早但仍在活动的聊天；标题优先使用显式任务名，其次使用会话索引名称，最后才用生成标题。不自动读取其他主机或云端任务。

## 每个任务的标题和最新消息

有任务时默认显示居中对齐状态条的堆叠玻璃卡片。支持三态：**收缩**完全隐藏卡片，角色回到原位；**折叠**显示一摞卡片，角色只为这一摞让出空间；**展开**从堆叠相同的近端边缘铺开完整列表，角色不再追加位移。三态切换中状态条的停靠坐标保持固定；下半屏角色上移、卡片向上展开，上半屏角色下移、卡片向下展开。卡片上没有额外计数，任务数保留在状态条和无障碍说明中。

箭头（或整条状态胶囊）的操作与用户确认一致：展开时第一次点击折叠，再次点击完全收缩；收缩后点击显示折叠卡片。点击堆叠展开列表，点击外部或打开聊天退回折叠。用户明确收缩后，消息刷新不会自动显示卡片。按住状态条文字或箭头拖动仍可移动整个宠物；跨中线后松手换边，保持精确拖动终点。角色让位／还原和卡片展开／收起均有约 300ms 过渡，快速反向从当前位移继续；开启“减少动态效果”时直接切换。

每张卡片第一行为标题，第二行为最新公开进度／答复或活动状态。长消息截断，悬停可看最近一条助手消息；点击通过官方 `codex://threads/<id>` 打开原聊天，不发送消息。超过可见高度时滚动，换边保留逻辑滚动位置。无任务时不显示默认堆叠；右键“查看任务消息”可显式打开空列表提示。完成任务在原12秒窗口内保留最后答复。

列表快照位于 `~/Library/Application Support/LocalCompanions/BigFatBlueFish/codex-tasks.json`，独立于 `state.json`，不改变工作数量、庆祝去重或电饭锅动画。空闲、过期任务会从快照移除。原生玻璃卡片不会取得键盘焦点；关闭状态提示后可从右键菜单再次进入。

macOS 26 及以上的任务卡片和脚下状态条都使用直接渲染的原生 Regular Liquid Glass，不额外叠加 HUD 模糊底层；旧系统保留原生 vibrancy 兼容回退。具体尺寸、失焦处理、左右像素缺口的修复历史和构建验收见 [原生玻璃配置与修复记录](../../Native/FishStatusGlass/README.md)。

`tasks.py` 是本机存储格式兼容层；SQLite字段和会话日志不是公开稳定API。读取失败时保留任务状态，以“未命名任务”和通用状态降级。首次消息扫描限最近2MiB，超大的消息/输出会跳过；任务尚未写入可读消息时显示通用状态。不会用用户提问或隐藏推理冒充“最新消息”。

健康记录位于 `~/Library/Application Support/LocalCompanions/BigFatBlueFish/codex-observer.json`。日志位于 `~/Library/Logs/LocalCompanions/BigFatBlueFish/codex-observer*.log`，仅用于程序异常，不写聊天正文。

移除桌面监听：

```sh
python3 Integrations/codex/install-observer.py --remove
```

移动工程后需重新安装，因为 LaunchAgent 指向当前工程路径。安装与移除均保留原模型、本地应用和其他后台服务。

## 可选的官方 CLI hooks 方案

```sh
python3 Integrations/codex/install.py
```

安装器合并 `$CODEX_HOME/hooks.json`，保留已有 handlers、修改前自动备份。然后在 Codex CLI 的 `/hooks` 中审阅并信任标记为 **BigFish: local desktop state** 的 8 个 hooks。安装器不会写信任记录或改变审批权限。

此方式已通过真实 CLI 回合验证，适合能够加载这些 hooks 的会话。请在两种方式中选用一种，避免重复事件。本机当前启用的是桌面监听器，先前的 8 个 hooks 已从配置中移除；其他 hooks 和原有 notify 设置保留。

```sh
python3 Integrations/codex/install.py --remove
```
