直接使用
打开 Builds/BigFatBlueFish.app，无需同时启动 Unity 编辑器。
点击角色会开心；拖动角色可移动窗口；右键打开中文心情菜单和退出。
右键 → 动作… 可点播：挥挥手、女仆行礼、打个小盹、原地小碎步、开心跳跃。
待机时每隔约 8–15 秒随机挑选一个小动作，动作菜单中可关闭随机播放。
点击角色会做一次带轻微挤压回弹的开心跳跃；完成状态会庆祝一次。
窗口为 240×320 原生点，透明、置顶；角色外区域使用碰撞体近似命中穿透。
默认每秒 30 帧。自动眨眼、呼吸浮动和头部跟随已实现。

Q 版比例与动作
视觉参考：https://github.com/PC2005-cloud/dsh-pet
参考其更接近两头身的轮廓、短腿、动作前后回到待机、挥手/行礼/小憩等节奏。
当前仍为实时 3D 骨骼动画，使用自己的网格变形与程序动作，没有嵌入参考项目的视频。
原始模型完整保留于 Assets/Mzkagami；独立生成的 Q 版网格位于 Assets/DesktopFish/Generated。
按骨骼高度分区缩短腿部和躯干、略放大头部，并同步变换骨架、绑定矩阵与 137 个表情。
手臂与手掌按蒙皮骨骼权重单独处理：手臂长度缩小到 64%，袖管粗细从上臂 105% 平滑收到手腕 86%；
手部按黏土人参考重新分区塑形：掌心加宽加厚，指节单独缩短、指腹加圆；
手腕保留袖口过渡，手指骨骼与网格同步调整。待机双手靠近腰前，弯指幅度放松以适配更厚的手指；
挥手改为双手抬到脸侧、掌心朝前，肩肘保持弯曲；手腕小幅摆动后平滑收回腰前。
完整动作 5.2 秒，分抬手、停稳、挥动、收手四段，手指略弯并配合笑脸。
欢呼时展开手指并单独调整掌心朝向。
腿部高度压缩使用连续平滑曲线连接各区段；膝盖到脚踝逐渐增加厚度，向鞋底再平滑收细，
减少腿部与鞋袜连接处突然变细的感觉。轮廓参考 2D 图中圆润、紧凑的四肢。
头发与尾巴增加轻微程序摆动；这不等于迁移原版 VRChat PhysBone。

整体视觉对照（2D 参考原帧）
使用参考项目“点击回应-元气挥手”的正面原帧，对照站姿、服饰和头发轮廓。
头部纵向缩放从 108% 调整到 100%，保留 110% 宽度；耳鳍收小，减少横向尖翼感。
长发单独保留长度、扩大下半部轮廓并延伸到鞋边，转头/行礼时加入姿态补偿。
鱼尾末端降低，调整为更接近脚边的落点。
裙子与围裙分别变形：加深裙摆、保留底部花边厚度，减少露腿；围裙恢复圆润比例。
原鲸鱼图案通过独立材质采样移到围裙中央并放大，花边与源贴图保持原样。
渲染增加柔和、略暖的低饱和配色，透明背景保留；菜单不受调色影响。
取景与动作采样排除原模型 alpha=0 的隐藏面片，避免不可见几何撑大窗口留白。
本地模型采用 Q 版比例适配，保留 3D 结构与线条。

桌面轻量化
默认窗口从 360×480 缩小为 240×320 原生点，同一 Retina 缩放下渲染面积减少约 56%。
生成模型从 65,083 个三角面 / 44,618 个顶点，降到 43,815 个三角面 / 30,033 个顶点。
脸、眼睛、手与身体皮肤、少于 800 三角面的细小配件保留原始拓扑。
长发、尾巴、大块衣服等使用按法线/UV 误差约束的索引减面，边界锁定；保留下来的顶点不重采样。
完全透明的生成几何及材质槽从运行版移除，材质槽从 42 减到 38。
离线工具基于 meshoptimizer (MIT)，源码与编译入口位于 Tools/，不会装进桌宠运行程序。
本机缺少 Tools/bin/meshopt-reduce 时会通过 clang++ 自动构建，需要 Xcode Command Line Tools。
可用 DesktopFish.Editor.FishOptimizationReview.Run 重做六个动作的前后画面对照与所有表情检查。
统计和对照位于 work/optimization-review.json、work/optimization-comparison.png（上排优化前、下排优化后）。
CPU/GPU 帧耗时尚未专项基准测试；38 个材质槽和多层透明头发仍有进一步优化空间。

本地状态接口
python3 set-state.py working
python3 set-state.py complete
python3 set-state.py idle --action wave
动作参数支持 wave / bow / doze / step / cheer，可重复发送。
支持 idle / working / complete / waiting / error。
这只是本地状态文件接口，尚未自动订阅 Codex 桌面 App 当前聊天的任务状态。

修改源代码
Unity 2022.3.22f1 / Built-in Render Pipeline。
在 Unity 中打开这个文件夹；Desktop Fish 菜单可创建场景、渲染预览、构建应用。
也可运行 ./Build.command 自动构建。
编辑器可通过 UNITY_EDITOR_PATH 环境变量或本机 .unity-editor-path 文件指定；
当前本机配置复用先前已下载的 Unity 2022.3.22f1，无需重新下载。
编译时使用 MToon（UniVRM 0.128.1）和 UniWindowController 0.9.8。
当前个人许可证已通过 Unity Hub 登录启用。

MToon 与 UniWindowController 的开源许可保留于各自目录。
