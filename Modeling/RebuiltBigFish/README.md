# Rebuilt BigFish — editable model

`BigFish.blend` is the editable Blender model; `BigFish.glb` contains the portable rigged mesh. Unity uses `Assets/DesktopFish/Rebuilt/BigFish.prefab` and its two mesh assets. The Blender file opens in the generated idle pose. The GLB exports the bind/rest rig with neutral facial morph weights and no animation clips; Unity drives the gestures procedurally in `FishMotion.cs`.

This version authors mesh positions, topology, vertex colors, bones and six facial morphs in `Assets/DesktopFish/Editor/FishRebuiltModel.cs`. The generator does not read the previous 3D model, textures or skeleton. The character appearance is informed by the existing 2D pet and previous 3D screenshots; this is geometry provenance, not a claim of original character design.

Mesh density is recorded in `Assets/DesktopFish/Rebuilt/provenance.json`. The model uses two material slots, one generated 1024×1024 paint atlas, 51 bones and six expression morphs. Blender materials approximate the Unity toon shader rather than reproducing it exactly.

A topology cleanup removes 1,208 collapsed triangles and 77 unreferenced vertices. With the current cuff bands, mouth surface, crown tuft and skirt sampling, the model has 52,448 triangles and 32,078 vertices (29,980 body, 2,098 face). A triangle is discarded only when its area is below 1e-12 square model units and a coincident edge has matching skin weights and every expression delta. Cleanup runs after expression generation, remapping all retained attributes and morph frames together while preserving their authored normals. Multi-view and hand-pose pixel comparisons show only small rasterization differences; the 150-pose check and Blender/GLB validation pass. This is redundant topology removal, without deleting visual detail; frame-rate improvement has not been measured.

## Reproduce

1. Run Unity batch method `DesktopFish.Editor.FishRebuiltModel.ReviewAndBuild`. This creates the Unity assets, previews, geometry/idle-pose JSON under `work/`, and `Builds/RebuiltBigFish.app`.
2. Run Blender in background with `--factory-startup --python Modeling/RebuiltBigFish/build_blend.py` from the project root. This regenerates both editable exports from that JSON, with the idle pose applied to the rig.

For geometry iteration without rebuilding the app, run `DesktopFish.Editor.FishRebuiltModel.Review`. The Blender exporter checks the resulting GLB's packed image, UVs, authored colors, shading normals, joints, unlit face material and neutral facial weights. It also matches every exported position delta for all six named expression targets against the source mesh, including sparse glTF accessors and vertices split by export attributes.

`work/rebuilt-expressions.png` has front and 35-degree rows, with columns neutral, Joy 70%, Fun 25%, Sorrow 70%, Surprised 35%, Surprised 45%, closed eyes, and Joy 70% with smile eyes. `work/rebuilt-expression-extremes.png` uses neutral, the four expressions at 100%, Surprised 45% with closed eyes, Joy 70% with closed eyes, and Joy 70% with smile eyes. These previews are generated by `RenderAngles` alongside the existing gesture and hand views. `DesktopFish.Editor.FishWavePreview.RenderRebuilt` additionally renders the full wave at 24 fps and checks wrist/elbow continuity plus the combined blink/smile weight.

The normal legacy build remains separate in `Builds/BigFatBlueFish.app`. Generated Unity assets and exported Blender/GLB files should be regenerated together after changing model dimensions or paint.
